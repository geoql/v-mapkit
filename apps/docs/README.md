# v-mapkit Documentation

> Documentation site for v-mapkit — Vue 3 components for Apple MapKit JS

## Development

```bash
# Install dependencies
pnpm install

# Start dev server
pnpm run dev

# Build for production
pnpm run build
```

## Deployment

Deployed to the Cloudflare Worker `v-mapkit-docs` at https://v-mapkit.geoql.in via GitHub Actions (`pnpm run deploy` for a manual deploy).
